# Changelog

## v1.0.0 — First Public Release

- Interactive Uttamap location picker for the Dcashop checkout.
- Responsive desktop and mobile map interface.
- Current-location selection and optional address search.
- Street, province, and city lookup through Uttamap.
- Configurable public API key and optional server secret key.
- Delivery location display in WooCommerce order administration.
- Documentation and screenshots for GitHub.
